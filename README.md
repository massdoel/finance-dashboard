# 💰 Finance Dashboard

Dashboard rekapitulasi keuangan real-time dengan integrasi workflow otomatis.

## 🚀 Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Recharts** (charting)
- **Lucide React** (icons)
- **Vercel** (hosting + CDN)
